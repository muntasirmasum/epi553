Lab 2: One-Way ANOVA

Test whether blood pressure differs across BMI groups, then check the assumptions.

Labs
A guided ANOVA of systolic blood pressure by BMI category in NHANES, with Tukey comparisons and assumption checks, then a practice problem on mental health days and activity.

NoteLearning objectives

Time: about 30 minutes. Goal: practice one-way ANOVA from start to finish using real public health data.

  • Understand when and why to use ANOVA instead of multiple t-tests
  • Set up hypotheses for ANOVA
  • Conduct and interpret the F-test
  • Perform post-hoc tests when appropriate
  • Check ANOVA assumptions
  • Calculate and interpret effect size (η²)

Structure: Part A is a guided example to follow along; Part B is independent practice in your own file.

PART A: GUIDED EXAMPLE

Example: Blood Pressure and BMI Categories

Research Question: Is there a difference in mean systolic blood pressure (SBP) across three BMI categories (Normal weight, Overweight, Obese)?

Why ANOVA? We have one continuous outcome (SBP) and one categorical predictor with THREE groups (BMI category). Using multiple t-tests would inflate our Type I error rate.

Step 1: Setup and Data Preparation

Show the code
# Load necessary libraries
library(tidyverse)   # For data manipulation and visualization
library(knitr)       # For nice tables
library(car)         # For Levene's test
library(NHANES)      # NHANES dataset

# Load the NHANES data
data(NHANES)

Create analysis dataset:

Show the code
# Set seed for reproducibility
set.seed(553)

# Create BMI categories and prepare data
bp_bmi_data <- NHANES |>
  filter(Age >= 18 & Age <= 65) |>  # Adults 18-65
  filter(!is.na(BPSysAve) & !is.na(BMI)) |>
  filter(BMI >= 18.5) |>  # drop underweight so "Normal" means BMI 18.5-24.9
  mutate(
    bmi_category = case_when(
      BMI < 25 ~ "Normal",  # 18.5 to 24.9
      BMI >= 25 & BMI < 30 ~ "Overweight",
      BMI >= 30 ~ "Obese",
      TRUE ~ NA_character_
    ),
    bmi_category = factor(bmi_category, 
                         levels = c("Normal", "Overweight", "Obese"))
  ) |>
  filter(!is.na(bmi_category)) |>
  select(ID, Age, Gender, BPSysAve, BMI, bmi_category)

Step 4: Set Up Hypotheses

Null Hypothesis (H₀): μ_Normal = μ_Overweight = μ_Obese
(All three population means are equal)

Alternative Hypothesis (H₁): At least one population mean differs from the others

Significance level: α = 0.05

Step 5: Fit the ANOVA Model

Show the code
# Fit the one-way ANOVA model
anova_model <- aov(BPSysAve ~ bmi_category, data = bp_bmi_data)

# Display the ANOVA table
summary(anova_model)
               Df  Sum Sq Mean Sq F value Pr(>F)    
bmi_category    2   48077   24039   110.8 <2e-16 ***
Residuals    5900 1279509     217                   
---
Signif. codes:  0 '***' 0.001 '**' 0.01 '*' 0.05 '.' 0.1 ' ' 1

Interpretation:

  • F-statistic: 110.85
  • Degrees of freedom: df₁ = 2 (k-1 groups), df₂ = 5900 (n-k)
  • p-value: <2e-16
  • Decision: Since p < 0.05, we reject H₀
  • Conclusion: There is statistically significant evidence that mean systolic BP differs across at least two BMI categories.

Step 6: Post-Hoc Tests (Tukey HSD)

Why do we need this? The F-test tells us that groups differ, but not which groups differ. Tukey’s Honest Significant Difference controls the family-wise error rate for multiple pairwise comparisons.

Show the code
# Conduct Tukey HSD test
tukey_results <- TukeyHSD(anova_model)
print(tukey_results)

Step 7: Calculate Effect Size

Show the code
# Extract sum of squares from ANOVA table
anova_summary <- summary(anova_model)[[1]]

ss_treatment <- anova_summary$`Sum Sq`[1]
ss_total <- sum(anova_summary$`Sum Sq`)

# Calculate eta-squared
eta_squared <- ss_treatment / ss_total

cat("Eta-squared (η²):", round(eta_squared, 4), "\n")
Eta-squared (η²): 0.0362
Show the code
cat("Percentage of variance explained:", round(eta_squared * 100, 2), "%")
Percentage of variance explained: 3.62 %

Interpretation: BMI category explains 3.62% of the variance in systolic BP.

  • Effect size guidelines: Small (0.01), Medium (0.06), Large (0.14)
  • Our effect: Small

While statistically significant, the practical effect is modest: BMI category alone explains only 3.6% of the variation in blood pressure.

Step 8: Check Assumptions

ANOVA Assumptions:

  1. Independence: Observations are independent (this comes from the study design, not from a plot). In the NHANES teaching package some participants appear more than once because the data were resampled, so independence does not strictly hold here.
  2. Normality: Residuals are approximately normally distributed
  3. Homogeneity of variance: Equal variances across groups
Show the code
# Create diagnostic plots
par(mfrow = c(2, 2))
plot(anova_model)
par(mfrow = c(1, 1))

Diagnostic Plot Interpretation:

1. Residuals vs Fitted: Checking the Group Means

This plot checks if the relationship between our groups and blood pressure is captured correctly.

The Pattern: You see three distinct vertical “columns” of points. Each column represents one of our groups (Normal, Overweight, and Obese). In ANOVA, every person in a group has the same “fitted value” (the group mean).

The Conclusion: The red line is relatively flat and stays near zero. This is a good sign: the residuals in each group are centered on that group’s mean.

2. Normal Q-Q: Checking for Normality

This is the most important plot for this specific dataset. It checks if our residuals (the differences between observed and predicted BP) follow a normal distribution.

The Pattern: The points should follow the dashed diagonal line. Here, we see the points curving upward away from the line at the top right.

The Conclusion: This indicates right-skewness. This is common in public health data, where “high BP outliers” stretch the distribution. However, because our sample is very large (N = 5,903), the Central Limit Theorem tells us that ANOVA is robust to this violation.

3. Scale-Location: Checking for Equal Variance (Homoscedasticity)

This plot checks if the “spread” of blood pressure is roughly the same within each BMI category.

The Pattern: We want to see a flat red line and columns of points that are roughly the same height.

The Conclusion: Compare the heights of the three columns. Levene’s test below gives p = 0.065, so it does not reject equal variances, though only just.

4. Residuals vs Leverage: Identifying Influential Outliers

This plot helps us see if any single data point (one person’s BP) is so extreme that it is pulling the group mean and “faking” our results.

The Pattern: We look for points in the corners that cross the dashed contour lines labeled “Cook’s distance.” Here every point has very low leverage, so the contours fall outside the plotted area and only the legend entry shows.

The Conclusion: R labels the three most extreme points with their row numbers. The largest Cook’s distance is 0.0096, far below the 0.5 contour, so no single person is driving our results.

Summary of Assumption Checks
ANOVA Assumption Check Summary
Plot Assumption Status Interpretation for this example
Residuals vs Fitted Residuals centered on group means Met The red line is flat. The vertical ‘strips’ represent our three BMI groups.
Normal Q-Q Normality Minor violation (right skew) Residuals are right-skewed. With N = 5,903, ANOVA is robust to this.
Scale-Location Equal Variance Met (Levene p >= 0.05) Compare the spread of the three columns; Levene’s test gives the formal answer.
Residuals vs Leverage No Influential Outliers Met The largest Cook’s distance is 0.0096; no single person is warping the means.
Final Takeaway

While the Normal Q-Q plot shows that the residuals are somewhat skewed, our large sample size and the other three plots mean the F-test and the Tukey comparisons above can be trusted. In practice, check the assumptions before you interpret the F-test and the post-hoc tests.

Step 9: Report Results

Example Results Section:

We conducted a one-way ANOVA to examine whether mean systolic blood pressure (SBP) differs across BMI categories (Normal, Overweight, Obese) among 5,903 adults aged 18-65 from NHANES. Descriptive statistics showed mean SBP of 114.6 mmHg (SD = 15) for normal weight, 118.7 mmHg (SD = 13.9) for overweight, and 121.6 mmHg (SD = 15.3) for obese individuals.

The ANOVA revealed a statistically significant difference in mean SBP across BMI categories, F(2, 5900) = 110.85, p < 0.001. Tukey’s HSD post-hoc tests found 3 of 3 pairwise comparisons significant (p < 0.05): obese adults had on average 7 mmHg higher SBP than normal-weight adults, and 2.9 mmHg higher than overweight adults.

The effect size (η² = 0.036) indicates that BMI category explains 3.6% of the variance in systolic blood pressure, representing a small practical effect. These findings support the well-established relationship between higher BMI and elevated blood pressure, though other factors account for most of the variation in SBP.

Step 1: Data Preparation

Show the code
# Prepare the dataset
set.seed(553)

# 2009-2010 only: in that cycle active days were asked of exactly the active
mental_health_data <- NHANES |>
  filter(SurveyYr == "2009_10") |>
  filter(Age >= 18) |>

      PhysActive == "No" ~ "None",
